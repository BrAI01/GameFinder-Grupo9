# 01 - Requerimientos

## GameFinder

**Grupo 9**

## Objetivo general

Desarrollar una aplicación de terminal en Python que permita consultar un catálogo de videojuegos e incorporar progresivamente las estructuras de datos estudiadas en la materia.

## Requerimientos funcionales

1. Cargar videojuegos desde un archivo JSON.
2. Buscar videojuegos por título mediante búsqueda secuencial.
3. Buscar videojuegos por título mediante búsqueda binaria.
4. Listar videojuegos del catálogo.
5. Filtrar videojuegos por género.
6. Buscar y recorrer videojuegos mediante un Árbol Binario de Búsqueda.
7. Buscar y recorrer videojuegos mediante un árbol AVL.
8. Explorar una jerarquía de categorías mediante un árbol general o n-ario.
9. Obtener un ranking Top-N de videojuegos mediante una heap binaria basada en rating.

## Requerimientos no funcionales

- Implementación en Python.
- Interfaz de terminal.
- Código separado por módulos.
- Datos persistidos en JSON.
- Estructuras de datos implementadas manualmente cuando la consigna lo requiere.
- Repositorio Git público para la entrega y seguimiento del proyecto.

## Datos principales

Cada videojuego contiene:

- título;
- género;
- desarrollador;
- año;
- rating.
